# Dirección de arte y UI de ICAP

1. Audita el repositorio y toma como referencia el sitio oficial https://icapmx.com/ antes de modificar contenido. Distingue hechos verificados de propuestas.
2. Conserva el logo original y extrae de él el valor HEX naranja; si no está disponible, utiliza un token `--icap-orange` provisional y documenta que debe validarse. Propón base grafito, blanco y grises neutros.
3. Diseña primero un sistema de diseño: variables CSS para color, tipografía, espaciado (escala consistente), radios, contenedores y sombras sutiles. Evita valores sueltos repetidos.
4. Prioriza home con hero contundente, mensaje de valor claro, CTA a contacto, servicios, capacidades, proyectos/galería, empresa y contacto. Conserva rutas actuales cuando convenga, o sugiere redirecciones.
5. Servicios verificados: Diseño Mecánico, Manufactura, Eléctrico / Neumático, Control. Subservicios y marcas solo si están corroborados.
6. Usa fotografía industrial real de la empresa cuando esté autorizada. No presentar fotografías genéricas como proyectos reales de ICAP.
7. Diseña estados hover/focus, skeletons solo cuando tengan función, tarjetas de servicios, menús y botones con coherencia visual. Anima sutilmente, respetando movimiento reducido.
8. Genera HTML semántico, componentes reutilizables y recursos optimizados. Si no hay framework, no lo impongas sin justificar.
9. Revisa visualmente escritorio, tableta y móvil. Corrige composición, espacios, tamaño de textos y jerarquía antes de declarar terminado.
10. Entrega resumen de decisiones de diseño y una lista de fotos/logos/confirmaciones que el cliente debe aportar.

## Entregables esperados
Una interfaz moderna, empresarial y legible que transmita precisión, confianza e innovación, no una plantilla genérica.
